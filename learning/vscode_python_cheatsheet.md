
# 🚀 Cheatsheet Raccourcis VSCode pour Développeur Python

---

## 🔀 Navigation
- `Ctrl + → / ←` : mot suivant / précédent
- `Home / End` : début / fin de ligne
- `Ctrl + Home / End` : début / fin du fichier
- `Ctrl + Shift + O` : aller à un symbole (fonction/classe)
- `Ctrl + P` : ouvrir un fichier rapidement
- `Ctrl + G` : aller à une ligne

---

## ✍️ Édition de code
- `Shift + Alt + ↓ / ↑` : dupliquer la ligne/sélection
- `Ctrl + Shift + K` : supprimer une ligne
- `Alt + ↓ / ↑` : déplacer une ligne
- `Alt + Click` ou `Ctrl + Alt + ↓` : multi-cursors
- `Ctrl + F2` : sélectionner tous les mots similaires
- `Ctrl + D` : sélection suivante identique

---

## 🧼 Formatage & refactoring
- `Shift + Alt + F` : formater le fichier
- `F2` : renommer une variable
- `Ctrl + .` : actions rapides (extraction, suggestions)

---

## 🐛 Debug / Exécution
- `F5` : lancer l'application (si configurée)
- `Ctrl + F5` : exécuter fichier Python
- `F9` : ajouter un breakpoint
- `F10 / F11` : step over / into

---

## 🔧 Terminal intégré
- `Ctrl + \`` : ouvrir/fermer le terminal
- `Ctrl + Shift + \`` : nouveau terminal
- `Ctrl + Tab` : basculer entre terminaux

---

## 🔎 Recherche
- `Ctrl + F` : chercher dans fichier
- `Ctrl + Shift + F` : chercher partout
- `Ctrl + H` : remplacer

---

## 📦 Git & versioning
- `Ctrl + Shift + G` : panneau Source Control
- ✔ en haut à gauche : commit rapide

---

## 🧠 Bonus Python
- `Ctrl + Shift + P` → `Python: Select Interpreter`
- `Ctrl + P` puis `>reload` → recharger fenêtre
- `Ctrl + Shift + P` → `Preferences: Open Settings (JSON)`
